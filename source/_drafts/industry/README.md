# 概述
* 给普通人看的行业分析
* 通过对行业的剖析来找寻在当下社会的发展
* 可以从不同的视角来看,可以加入漫画元素
* 先画出这个行业的大概的运行流程，上、中、下游涉及到哪些领域，每个领域都涉及到的角色
* 这个行业的发展历史，如快递行业在古代关联驿站等
* 通过这种调研也锻炼自己的能力，开拓视野
* 资料查找：主要是通过网上、政府网站，上市公司的财务报告等
  * 缺点是这种能资料检索的只是一种整合，每个行业肯定有他自己的一些潜在的规则，这个需要深入实际中去挖掘才能探查到
* 可以以一个包裹的物流为例，来分析整个物流行业，分析这个包裹在这个过程中都是经过了什么，分析它的经历，
  * 其实可以结合AI做个包裹的动画
